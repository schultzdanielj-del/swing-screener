# 3-4db Example Charts

This folder contains 8 curated example charts of the 3-4 Day Bounce setup.

## Examples

| File | Ticker | Notes |
|------|--------|-------|
| CLSK_3db_bf.png | CLSK | 3db breach & fail at $20 level |
| PATH_3db.png | PATH | 3db stall at $17.33 level |
| LEU_3db_bf.png | LEU | 3d bounce short breach & fail at ~$400 |
| FLNC_3db.png | FLNC | 3db at $18.48 level |
| SEI_3db.png | SEI | 3db at $39.07 level |
| TTMI_3db.png | TTMI | 3db at $58.71 level |
| INOD_3db.png | INOD | 3db at $55.23 level |
| OPEN_3db.png | OPEN | 3db at $9.36 level |

To add images: copy PNG files from your local machine into this directory.

```bash
# From repo root
cp ~/path/to/charts/*.png setup_library/3-4db/examples/
git add setup_library/3-4db/examples/
git commit -m "Add 3-4db example charts"
git push
```
